# Política de segurança documental

Este repositório é público. Não abra Issues públicas com incidentes, dados reais ou evidências do ambiente.

## Conteúdo proibido

- Dados pessoais e listas de usuários.
- Tenant ID, Object ID, Device ID e Application ID reais.
- Domínios internos, IPs, topologias ou regras sensíveis.
- Logs, exportações, relatórios, rollback e evidências reais.
- Senhas, chaves, tokens, segredos, certificados e product keys.
- Links de instalação com token e capturas sem sanitização.

Em caso de publicação acidental, remova o acesso ao segredo, rotacione-o imediatamente e trate o evento conforme o processo interno de resposta a incidentes.
