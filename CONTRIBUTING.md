# Como contribuir

1. Abra uma Issue descrevendo a necessidade.
2. Crie uma branch, por exemplo `docs/novo-procedimento`.
3. Copie o modelo adequado da pasta `templates`.
4. Substitua qualquer dado real por exemplos fictícios.
5. Execute `mkdocs build --strict`.
6. Abra um Pull Request e preencha o checklist.
7. Aguarde a revisão antes do merge.

## Convenção de commits

- `docs:` novo conteúdo ou melhoria documental.
- `fix:` correção de instrução ou link.
- `security:` sanitização ou correção de exposição.
- `chore:` manutenção da estrutura.
