# Monitoramento no Intune

1. Acesse **Intune admin center > Aplicativos > Todos os aplicativos**.
2. Abra o aplicativo desejado.
3. Consulte **Visão geral**, **Status de instalação do dispositivo** e **Status de instalação do usuário**.
4. Registre instalado, falha, pendente e não aplicável.
5. Investigue códigos de erro antes de alterar comandos ou detecção.
6. Anexe as evidências ao registro de implantação.
