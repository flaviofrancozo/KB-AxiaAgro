# Correção visual — Portal da Empresa

Este pacote corrige a página inicial do Portal da Empresa para exibir o cabeçalho visual e os cards mostrados na prévia.

## Envio no GitHub

1. Acesse `docs/intune/portal-empresa` no repositório `KB-AxiaAgro`.
2. Clique em **Add file > Upload files**.
3. Envie o arquivo `index.md` contido neste pacote.
4. Confirme a substituição do `index.md` existente.
5. Use a mensagem de commit `Corrige página visual do Portal da Empresa`.
6. Aguarde o deployment da Cloudflare ficar **Success/Deployed**.
7. Acesse **Intune > Portal da Empresa > Visão geral** e pressione `Ctrl + F5`.

Não altere o `mkdocs.yml` nem o `extra.css`; eles já estão corretos na branch `main`.
