# Logs publicáveis

Esta pasta aceita somente evidências sanitizadas.

Não enviar:

- logs originais de produção;
- `hash.txt` real;
- caminhos de compartilhamentos internos;
- nomes de usuários;
- credenciais, tokens ou segredos;
- mensagens que revelem arquitetura sensível.

Os arquivos `EXEMPLO_*` usam dados fictícios e existem apenas para demonstrar o formato das evidências.
