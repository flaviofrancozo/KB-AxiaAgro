# Procedimentos

Use `templates/procedimento.md` para criar um procedimento operacional. O artigo deve ser testável, conter validação e evitar qualquer dado real.

## Fluxo padrão

1. Inventário ou detecção.
2. Prévia da alteração.
3. Aprovação.
4. Execução controlada.
5. Validação pós-execução.
6. Registro do resultado.
